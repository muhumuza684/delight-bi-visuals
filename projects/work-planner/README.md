# Work Planner

**DELIGHT INSIGHTS** - DATA DRIVEN DECISIONS. *A Bryt Ma Tech business intelligence unit.*

## Build

```
npm install
npm run ci      # typecheck + tests + package
```

The `.pbiviz` appears in `dist/`.
