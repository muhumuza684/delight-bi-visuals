# Universal Table

**DELIGHT INSIGHTS** - DATA DRIVEN DECISIONS. *A Bryt Ma Tech business intelligence unit.*

A table workspace with search, sorting, grouping, a pivot mode, column controls, filters, conditional formatting, calculated and combined columns.

## Build

```
npm install
npm run ci      # typecheck + tests + package
```

The `.pbiviz` appears in `dist/`.
