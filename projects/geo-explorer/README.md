# Geo Explorer

**DELIGHT INSIGHTS** - DATA DRIVEN DECISIONS. *A Bryt Ma Tech business intelligence unit.*

A real map with country borders: plot locations as bubbles by latitude and longitude, or fill countries by name, with a ranked list.

## Build

```
npm install
npm run ci      # typecheck + tests + package
```

The `.pbiviz` appears in `dist/`.
